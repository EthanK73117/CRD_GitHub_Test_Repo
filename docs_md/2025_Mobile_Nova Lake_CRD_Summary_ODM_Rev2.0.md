## Slide 5

**Highlights**

- For MoB design, all customers use Hardware strap to deliver correct memory configuration to BIOS.
- 5/8 customers(LCFC, Huaqin, Inventec CQ, Pega SZ and Compal KS) have MoP or PoP memory dipping experience.
- Customers don’t monitor the X-ray dosage on the memory during X-ray inspection.
- All customers don’t have any pre-SMT or post-SMT top-side die geometric (flatness, parallelism, etc.) expectations.
- Most customers apply adhesive before function test. If adhesive must be done after function test, production line layout update is their main concern.
- Most customers’ software can not detect and inspect flux dipping quality when flux is transparent.
- Only Huaqin, Pegatron SZ and Compal KS have experience on 01005 passive component.
- LCFC and Pegatron SZ have experience on recycled solder paste. SJ quality and reliability are customers’ main concern.
- LCFC, Huaqin, Inventec CQ and Compal KS have PoP package rework experience, but no customers has experience of memory replacement with edge or corner glue.
- Most customers have Debug POST card at their debug station.
